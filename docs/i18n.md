# Interface translations

English UI copy is the catalog key. The eleven non-English catalogs must have the same keys and preserve every `{placeholder}`. Brand names, command examples, paths, user messages and code are not translation targets.

## Dynamic text

Use `formatText("Shared on {date}. New messages aren't included.", { date })` for a complete sentence. Do not split a sentence around JSX expressions: the fallback DOM translator reads individual text nodes and cannot infer their relationship or reorder fragments. `formatText` preserves supplied values literally; translate known UI values explicitly before passing them. In contrast, the older `tf` helper also translates recognized values.

Subscribe with `useLocale()` or `useT()` in mounted components that format dates, numbers or messages. Use the selected locale with `Intl`, preserving stored protocol values and the original currency. Mark user-authored names and explicitly interpolated content with `data-no-translate` when necessary. The DOM fallback translates `aria-valuetext` as well as labels, titles, alternatives and placeholders, but respects explicit exclusions and user/code regions.

## Regression checks

Run `node --import tsx --test tests/i18n*.test.ts`.

The tests check exact catalog parity, nonempty values, duplicate keys, placeholder multisets, every statically declared `t`/`tf`/`formatText` call, and a curated set of audited sharing/settings/consent messages. Mounted React tests use LinkeDOM to exercise repeated language switching, sharing states, accessibility attributes and preservation of user text, code and inputs. Formatting tests compare dates, numbers, units and currencies with the selected locale, and keep storage values unchanged.

The September 2026 audit added 74 keys per catalog (2,272 keys total per non-English catalog), including share privacy labels, complete dynamic sentences, usage summaries and consent copy. Static JSX/attribute extraction was reviewed for genuine UI copy; catalog parity alone does not prove that every possible UI string is translated. These tests are not a native-speaker review or a substitute for real-browser visual QA.
