# Code of conduct

Claudex follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep
discussions about the work. Harassment, personal attacks and discriminatory
language are not accepted in issues, pull requests, reviews or any other
project space.

To report behaviour that breaks this code, contact the maintainers privately
through GitHub (**Security → Report a vulnerability** works for anything that
should not be public). Reports are handled confidentially, and maintainers
may remove content, warn, or ban participants as the Covenant describes.
